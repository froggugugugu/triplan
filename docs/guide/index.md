## はじめての方へ

操作の前に、2つの読み物を用意しています。

- **[プロジェクト管理の基礎](project-management.md)** —
  プロジェクト管理をしたことがない方へ。QCD（品質・コスト・納期）と人・モノ・金の関係、
  管理の基本サイクル、よくある失敗。**ツールの操作は出てきません**
- **[triplanの使い所（コンセプト）](concept.md)** —
  何をして何をしないツールか、向いている場面、導入の段取り

## 全体の流れ

triplanは「**枠を作ってから、リソースを当て込む**」流れで使います。

1. **[はじめに](getting-started.md)** — 起動・初期設定ウィザード・デモデータ・画面の全体像
2. **[計画を立てる](planning.md)** — チーム／プロジェクト・WBS／スケジュール／アサイン
   （WBSより前の超概算と段階ごとの見積の記録は **[見積と不確実性コーン](estimation.md)**）
3. **[予算とEVM](budget.md)** — 部門予算・案件概算・原価4区分・EVM・ダッシュボード
4. **[月次実績と締め](actuals.md)** — 実績の確認・確定・CSV取込・月次締め
5. **[商流とレポート](commerce.md)** — 受注・請求・変更管理・月次明細（準委任精算）・CSV帳票
6. **[外部ツール連携](integration.md)** — Backlog/Asana/Jira/GitHubへのAPI起票・完了同期・チャット通知・公開API
   （接続の準備は **[セットアップ手順](external-tools-setup.md)**）
7. **[権限とシステム設定](admin.md)** — 5ロール・金額の表示制御・業務定数・マスタ管理
8. **[本番セルフホスト](self-host.md)** — Docker Composeでの常駐構成・バックアップ・更新手順

## 月次の運用サイクル（推奨）

| タイミング | やること | 画面 |
| --- | --- | --- |
| 随時 | アサイン計画のメンテナンス・WBS完了チェック（または外部ツール同期） | アサイン／WBS |
| 月初 | 前月実績のレビュー→修正→**確定** | 月次実績 |
| 月次処理後 | 管理職が**締め**（以降その月は変更不可） | 月次実績 |
| 支払・請求時 | 月次明細の確認・CSV出力（協力会社への支払／発注元向け） | 月次明細 |
| 検収・請求時 | 請求マイルストンのステータス更新 | プロジェクト（商流） |
| 随時 | ダッシュボードのアラートセンターを確認 | ダッシュボード |
